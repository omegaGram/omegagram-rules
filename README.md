# правила юзернеймов

## основные требования

| правило                                | пример                              |
| -------------------------------------- | ----------------------------------- |
| только английские буквы, цифры и `_`   | ✅ `@hello`, `@testing5`             |
| длина от 3 до 32 символов              | ✅ `@hello`                          |
| можно начинать с цифры                 | ✅ `@12345`                          |
| нельзя начинать или заканчивать на `_` | ❌ `@_alex`, `@alex_`                |
| нельзя ставить несколько `_` подряд    | ❌ `@foo__bar`                       |
| регистр не учитывается                 | `@hello` и `@HELLO` — один юзернейм |

символ `@` в длину юзернейма не входит.

---

## запрещённые юзернеймы

нельзя использовать:

```text
@passport
@settings
@omegagram
@official
@durov
@monk
@crow
@unbrokensociety
@kodakruso
@juli
@julivavilova
```

также запрещены любые юзернеймы, которые начинаются с:

```text
telegram
admin
administrator
```

например:

```text
@telegramnews
@adminsupport
@AdministratorTest
```

проверка происходит без учета регистра.

---

## системные юзернеймы

по спецификации telegram deep links запрещены:

```text
@contact
@share
@joinchat
@addlist
@addstickers
@addemoji
@addtheme
@proxy
@socks
@invoice
@setlanguage
@confirmphone
```

---

## юзернеймы ботов

обычный пользователь не может использовать юзернейм, который заканчивается на `bot`.

```text
@musicbot
@test_bot
@coolbot
```

такие юзернеймы доступны только ботам и системным аккаунтам.

---

## запрещённый контент

нельзя использовать юзернеймы с:

* оскорблениями
* угрозами
* экстремизмом
* пропагандой
* призывами к насилию
* другим запрещённым контентом

за нарушение администрация может снять юзернейм, заморозить аккаунт или выдать бан.

---

## смена и освобождение юзернейма

после смены юзернейма старый юзернейм может быть временно недоступен.

юзернеймы заблокированных аккаунтов автоматически не освобождаются.

если аккаунт был удалён за нарушение, его юзернейм может навсегда попасть в бан-лист.

администрация также может отозвать юзернейм у давно неактивного аккаунта.

---

## массовое занятие юзернеймов

запрещено массово занимать юзернеймы для:

* перепродажи
* обмена
* удержания
* вымогательства
* создания искусственного дефицита

такие юзернеймы могут быть сняты, а аккаунты — заблокированы.

---

## права администрации

администрация может:

* снять юзернейм
* временно или навсегда его заблокировать
* зарезервировать его для системы
* вернуть предыдущему владельцу
* добавить новый юзернейм или префикс в бан-лист

даже если юзернейм подходит под все правила, он всё равно может быть недоступен из-за системных ограничений, блокировки или резерва.
